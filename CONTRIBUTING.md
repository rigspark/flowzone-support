# Contributing to FlowZone support

Thanks for helping make YouTube feel like yours again.

## Opening an issue

1. **Search first.** If your idea or bug is already here, add a 👍 to it, and a comment if you have something new to add.
2. **Pick the right form:** feature request, bug report or channel report. The forms ask for exactly what we need to act on it.
3. **One thing per issue.** Two ideas are easier to track as two issues.
4. **Keep it public-safe.** Don't post emails, account details or anything personal.

## How we triage

| Label | Meaning |
| --- | --- |
| `feature` | A new idea or a change to how FlowZone works |
| `bug` | Something isn't working as described |
| `channel` | A missed AI channel, or a real creator hidden by mistake |
| `needs-info` | We need more detail from you before we can act |
| `planned` | We're going to build it |
| `shipped` | It's in a released version of FlowZone |
| `wont-do` | Out of scope for FlowZone. We'll always say why |

We read every issue. Ideas with the most 👍 move up the roadmap.

## Code of conduct

Be kind. Critique ideas, not people. We remove comments that are abusive, spammy or off-topic.
